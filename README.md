# Horti-Fruti Delivery

Projeto desenvolvido para as disciplinas PSI e SSO da FATEC São Roque.

## Tecnologias
- HTML
- CSS
- JavaScript
- Cloudinary
- JSON Server
- Render

## Funcionalidades

### Concluídas
- Catálogo de produtos
- Exibição dinâmica dos produtos
- Integração com imagens do Cloudinary

### Em desenvolvimento
- Busca
- Filtros
- Modal de detalhes
- CRUD
- Controle de estoque
